{% comment %} The provisional / unrated marker for one format rating (KAN-50 / S4.4). A word, in the `.label-cap` treatment, inside an outline -- never a colour on its own, and never amber (amber means live, and this is not). Unrated has a dashed outline and a different word, so it cannot be mistaken for provisional in greyscale either. Established renders nothing: the absence of a marker is the "this number has settled" state. The threshold is decided in ratings.rating_status() (elo.PROVISIONAL_MATCHES, or the display RD under Glicko-2); this template only receives the verdict. Under Glicko-2 a provisional rating has a `reason`: 'new' keeps the word Provisional, 'returning' (wide from idle time) says Returning. Same outline. Context: `status` ('provisional' | 'unrated' | 'established'), `reason` (optional), `rating_system`. {% endcomment %} {% if status == 'provisional' %}{% if reason == 'returning' %}Returning{% else %}Provisional{% endif %}{% elif status == 'unrated' %}Unrated{% endif %}
