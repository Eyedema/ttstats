{% comment %} The provisional / unrated marker for one format rating (KAN-50 / S4.4). A word, in the `.label-cap` treatment, inside an outline -- never a colour on its own, and never amber (amber means live, and this is not). Unrated has a dashed outline and a different word, so it cannot be mistaken for provisional in greyscale either. Established renders nothing: the absence of a marker is the "this number has settled" state. The threshold is decided in ratings.rating_status() from elo.PROVISIONAL_MATCHES; this template only receives the verdict. Context: `status` ('provisional' | 'unrated' | 'established'). {% endcomment %} {% if status == 'provisional' %}Provisional{% elif status == 'unrated' %}Unrated{% endif %}
