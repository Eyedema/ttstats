{% extends "pingpong/base.html" %} {% load icon_tags live_tags static %} {% block title %}Live Scoreboard{% endblock %} {% comment %} No page transition into or out of the scoreboard (KAN-125). A cross-document view transition needs both pages to opt in, so re-declaring `none` here makes entering and leaving an instant swap: nothing is snapshotted over the tap zones and the first tap is never held behind an animation. The names are cleared too, so the chrome hidden under the board is never captured. Inline because it is one page's override of app.css; prod's style-src allows it. The other rules are the scoreboard's fail-closed contract (KAN-81). Every overlay below starts with the `hidden` attribute and only scoreboard.js removes it. Tailwind's preflight `[hidden]` rule loses to any display utility on the same element, so it is restated here with !important, inline, so it holds with no stylesheet at all. The game pips are styled by a data attribute because scoreboard.js toggles them and Tailwind never scans JS. Shared scoring (KAN-153): the server renders `data-shared` and `data-my-side` on #scoreboard for a phone that scores only its own side, and these rules (not a second template, not JS-added classes) turn the row of two zones into a column: the opponent's read-only score on top, my "+1" zone filling the rest at the bottom, nearest me. The side switch never moves them. {% endcomment %} {% block extra_css %} {% endblock %} {% comment %} The live scoreboard: read from a metre away, driven one-handed. Two tap zones floor to ceiling -- the whole coloured half IS the button, so there is nothing to aim at while holding a paddle. Each half wears its player's permanent hue, so the sides are the people. The digits are the one place in the app where type gets to be enormous. Serve is a solid dot PLUS the word SERVING. Never colour alone, and never the pulse alone: reduced motion parks the animation, and the word has to survive that. Games won are small bars rather than a number, because bars are countable at a glance and "2" is not distinguishable from "3" across a room. Chrome is a 60px bar pinned above the home indicator: Undo bottom-left where a thumb already is, and Exit deliberately the quietest thing on screen. Offline-first (KAN-76): the page renders from local state = the server's state + the ops not yet acknowledged, kept in a durable outbox. All behaviour lives in static files -- live_rules.js (the rules mirror), live_outbox.js, live_session.js (flush loop + reconcile) and scoreboard.js (this DOM) -- plain JS, so it runs under a CSP with no 'unsafe-eval'. Read .claude/rules/live-scoring.md "Scoreboard client" before touching it. {% endcomment %} {% block full_bleed %} {% csrf_token %} {{ bootstrap|json_script:"scoreboard-bootstrap" }} {{ scoreboard_config|json_script:"scoreboard-config" }} {% live_rules_config %}
